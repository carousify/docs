The OpenAI [Codex CLI](https://developers.openai.com/codex/mcp) supports remote MCP servers over Streamable HTTP. Add Carousify with your MCP key and you can ask Codex to draft posts, build carousels, schedule them, or pull analytics from any terminal session.

## Before you start

- A Carousify workspace on a plan with MCP access, and a role that can create MCP keys. See [Before you start](/mcp/overview#before-you-start).
- A recent version of the Codex CLI, signed in (`codex login`).

## Step 1: Create an MCP key

In Carousify, open **Manage Workspace › MCP**. Type a label in **API Name** (for example `codex`) and click **Create API Key**, or click **Enable MCP** if MCP isn't enabled yet. Copy the MCP URL that appears:

```
https://api.carousify.com/mcp?token=YOUR_MCP_KEY
```

<Warning>
  Carousify shows the full key only once. Treat it like a password: anyone with it can use your workspace with your role's permissions.
</Warning>

## Step 2: Add Carousify to Codex

<Steps>
  <Step title="Recommended: keep the key in an environment variable">
    Put the key (the part after `token=`) in your shell profile:

    ```bash
    export CAROUSIFY_MCP_KEY="your_mcp_key"
    ```

    Then add this to `~/.codex/config.toml`:

    ```toml
    [mcp_servers.carousify]
    url = "https://api.carousify.com/mcp"
    bearer_token_env_var = "CAROUSIFY_MCP_KEY"
    ```

    Codex sends the key as a Bearer token, and your `config.toml` stays free of secrets.
  </Step>
  <Step title="Or: add it with one command">
    This is what the **Codex CLI** tab on Carousify's MCP page shows. The key is part of the URL, so it's saved in `config.toml`:

    ```bash
    codex mcp add carousify --url "https://api.carousify.com/mcp?token=YOUR_MCP_KEY"
    ```
  </Step>
  <Step title="Check the connection">
    Run:

    ```bash
    codex mcp list
    ```

    `carousify` should be listed. In a Codex session, `/mcp` shows the server and its tools.
  </Step>
</Steps>

## Step 3: Use it from a Codex session

Start a session (`codex`) and try:

- *"Using Carousify, draft a LinkedIn post about today's release notes and schedule it for 9 AM tomorrow."*
- *"List my scheduled Carousify posts for this week."*
- *"Pull Carousify analytics for the post I published yesterday."*

Codex asks for your approval before running tools. Mention Carousify in the prompt the first few times so Codex picks the right tools. See the [tools reference](/mcp/tools).

## Disconnect or rotate

- **Disconnect:** run `codex mcp remove carousify`, or delete the `[mcp_servers.carousify]` block from `config.toml`.
- **Rotate the key:** in Carousify, delete the key in the **MCP Keys** table, create a new one, and update the environment variable or URL.

## Troubleshooting

- **401 "Invalid API key!"** The key is wrong, turned off or deleted. Check it shows as on in **MCP Keys**, and that you used the full key, not the masked `XXXX…` version.
- **"This MCP key was created by someone who is no longer in this workspace."** Create a new key.
- **Older setups:** if your `config.toml` points at `app.carousify.com/api/mcp`, change it to `https://api.carousify.com/mcp`.
