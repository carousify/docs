The Carousify MCP server lets AI assistants that speak the [Model Context Protocol](https://modelcontextprotocol.io/) work in your Carousify workspace. Once connected, you can ask the assistant to write a post, build a carousel from one of your templates or design a new one, schedule it, and check how it performed, all from the chat.

The server is a remote MCP server at:

```
https://api.carousify.com/mcp
```

There's nothing to install. It uses the Streamable HTTP transport, and each connection works in one workspace: the one you pick when you sign in, or the one the API key belongs to.

<Note>
  MCP is for when you want an AI assistant to act on Carousify. If you only want notifications when something happens, the [Slack](/integrations/slack), [Zapier](/integrations/zapier) and [Webhook](/webhooks/overview) integrations are simpler.
</Note>

## What you can do

| Use case | Example prompt |
| --- | --- |
| Draft and schedule posts | *"Write a LinkedIn post about our new feature and schedule it for Tuesday 9 AM."* |
| Build a carousel from a template | *"Turn this article into a 7-slide carousel using one of my templates and my brand kit."* |
| Design a brand-new carousel layout | *"Design a new carousel template for a product launch in our brand colors."* |
| Post a carousel | *"Post that carousel to my company page as a PDF tomorrow at 10 AM."* |
| Use your own files | *"Here's a photo from the event. Draft an Instagram post with it."* |
| Review posts waiting for approval | *"Show me the posts waiting for approval and approve the one about pricing."* |
| Check performance | *"How did my last five LinkedIn posts do? What should I post next?"* |

Everything the assistant creates is saved in Carousify first: posts as drafts, carousels as drafts you can open in the [Carousel Maker](/carousel-maker/overview). Nothing is published or scheduled unless you ask for it. See the [tools reference](/mcp/tools) for the full list.

## Two ways to connect

| | Sign in (OAuth) | MCP API key |
| --- | --- | --- |
| **Best for** | Claude, ChatGPT, Grok | Cursor, VS Code, Codex CLI, Antigravity, Claude Code and other developer tools |
| **What you paste** | `https://api.carousify.com/mcp` | `https://api.carousify.com/mcp?token=YOUR_MCP_KEY`, or the plain URL plus an `Authorization: Bearer YOUR_MCP_KEY` header |
| **How the workspace is chosen** | You sign in to Carousify and pick it on a consent screen | The workspace the key was created in |
| **Acts as** | You, with your workspace role | The member who created the key, with their role |
| **Disconnect** | **Connected apps** table, or remove it in the assistant | Turn off or delete the key in the **MCP Keys** table |

Sign-in is the simpler and safer choice when your assistant supports it: there's no key to copy or leak, and the connection stops working if you leave the workspace. See [Permissions and security](/mcp/permissions) for details.

## Before you start

- **A plan with MCP access.** MCP depends on the workspace owner's plan. If the plan doesn't include it, the MCP page shows an **Upgrade** link. See [Plans and pricing](/billing/plans).
- **Permission to connect apps.** Your role in the workspace must allow creating MCP keys. Without it, the workspace is greyed out on the sign-in screen and **Enable MCP** shows a permission error. Ask the workspace owner if you're unsure.
- **At least one connected account** to post to. See [Connect LinkedIn](/getting-started/connect-linkedin).

In Carousify, open **Manage Workspace › MCP**.

The page has four parts:

1. **Connect with sign-in** shows the MCP server URL to paste into Claude, ChatGPT or Grok. No key needed.
2. **Setup MCP** is where you create MCP API keys. The first time, click **Enable MCP**: Carousify creates a key named **MCP System Key** and shows its MCP URL once. Below it, tabs for **Claude**, **Cursor**, **VS Code**, **Codex CLI**, **ChatGPT** and **Antigravity** show short setup steps for each client.
3. **MCP Keys** lists every MCP key in the workspace.
4. **Connected apps** lists the assistants that signed in to this workspace with OAuth, who connected them, and when they were last used.

## Managing MCP keys

To create a key for a specific client, type a label in **API Name** (for example `cursor-laptop` or `codex`) and click **Create API Key**. Carousify shows the full MCP URL once, right after you create the key. Copy it straight away: afterwards the table only shows the last few characters, and there's no way to show the key again.

In the **MCP Keys** table you can:

- **Turn a key off** with the **Status** switch. Requests with that key are refused until you turn it back on.
- **Delete a key** with the trash icon. Any client still using it stops working. To replace a lost or leaked key, delete it and create a new one.

<Warning>
  Treat an MCP key like a password. Anyone with the URL and key can use your workspace through Carousify with the permissions of the member who created the key.
</Warning>

## Supported clients

| Client | How it connects | Guide |
| --- | --- | --- |
| Claude (web, desktop, mobile) | Sign in | [Claude](/mcp/claude) |
| Claude Code | Sign in or MCP key | [Claude](/mcp/claude#claude-code) and the [Claude Code plugin](/mcp/claude-plugin) |
| ChatGPT | Sign in | [ChatGPT](/mcp/chatgpt) |
| Grok | Sign in | [Grok](/mcp/grok) |
| Cursor | MCP key | [Cursor](/mcp/cursor) |
| VS Code | MCP key | [VS Code](/mcp/vscode) |
| Codex CLI | MCP key | [Codex CLI](/mcp/codex) |
| Antigravity | MCP key | [Antigravity](/mcp/antigravity) |

Other MCP clients work too, as long as they support remote servers over Streamable HTTP. Use sign-in if the client supports OAuth, otherwise the URL with `?token=` or a Bearer header.

<Tip>
  If you set up Carousify with an older guide, your client may still point at a URL that starts with `https://app.carousify.com/api/mcp`. Replace it with `https://api.carousify.com/mcp`, keeping your `?token=` if you use a key.
</Tip>
